Scrivici a konechocoproduction@gmail.com. Se ti è possibile, allega il riepilogo da Amministrazione → Sistema e assistenza → Copia riepilogo (non contiene password né dati).

Provare l'app

Apri l'app e tocca Entra nella demo: ti colleghi al gateway dimostrativo pubblico con dati di esempio (utente demo, password plexa-demo).

Collegare i database della tua azienda

Il reparto IT installa il gateway Plexa DB su un PC o server della rete aziendale e aggiunge le connessioni (IBM i / AS400, PostgreSQL, MySQL, SQL Server, Oracle, Snowflake). Poi, nell'app, tocca Scansiona QR del gateway e inquadra il codice in Amministrazione → Dispositivi, oppure scrivi l'indirizzo del gateway. Fuori ufficio serve la VPN aziendale.

Problemi frequenti

  • Gateway non raggiungibile: controlla di essere sulla rete dell'ufficio o in VPN e che il gateway sia avviato con PLEXA_HOST=0.0.0.0.
  • IBM i: timeout: la porta del database è la 446 (non la 23 dell'emulatore 5250); il firewall deve permettere 446, 449 e 8470–8476.
  • Password dimenticata: un amministratore la reimposta in Amministrazione → Utenti.

Informativa sulla privacy

Plexa DB — Support

Write to konechocoproduction@gmail.com. If possible, attach the summary from Administration → System & support → Copy summary (no passwords or data).

Try the app

Open the app and tap Enter the demo: you connect to the public demo gateway with sample data (user demo, password plexa-demo).

Connect your company databases

IT installs the Plexa DB gateway on a PC or server in the company network and adds the connections (IBM i / AS400, PostgreSQL, MySQL, SQL Server, Oracle, Snowflake). Then, in the app, tap Scan gateway QR and point at the code in Administration → Devices, or type the gateway address. Outside the office you need the company VPN.

Common issues

  • Gateway unreachable: make sure you are on the office network or VPN and that the gateway runs with PLEXA_HOST=0.0.0.0.
  • IBM i: timeout: the database port is 446 (not 23, the 5250 emulator); the firewall must allow 446, 449 and 8470–8476.
  • Forgotten password: an administrator resets it in Administration → Users.
